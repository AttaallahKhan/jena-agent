# Jena Foundation

## Goal
Build Jena into a self-evolving agent that can learn, remember, improve, and recover safely.

## Evolution Pipeline
Observe → Learn → Remember → Plan → Validate → Backup → Apply → Test → Verify → Rollback

- [ ] M7 — Persistent Skills

- [ ] M9 — Autonomous Evolution

## Safety Rules

1. Never lose existing knowledge.
2. Never apply untested code.
3. Always keep a known-good version.
4. Failed changes must rollback automatically.
5. API keys and secrets never go into source code.
